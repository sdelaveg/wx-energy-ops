# Predicción de Carga Energética (Facility Management)

Repositorio oficial para la Actividad 5 de la Maestría en Inteligencia Artificial (Universidad Tecmilenio).

**Autor:** Sergio Eduardo de la Vega Herrera (Sergie)

## Estructura del Repositorio
- `datos/datos_ini/`: Contiene el dataset original de la UCI.
- `datos/datos_limp/`: Contiene el dataset limpio y estandarizado con StandardScaler.
- `fuentes/`: Scripts de preparación (`datos_prep.py`) y entrenamiento (`train.py` con MLflow y SQLite).
